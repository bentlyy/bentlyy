## 📂 Proyectos Destacados

### 🏥 Sistema de Gestión Clínica — *Clínica Salud Vital*
[![Render](https://img.shields.io/badge/Deploy-Render-46E3B7?style=flat-square&logo=render&logoColor=white)](https://clinica-salud-vital.onrender.com)
[![GitHub](https://img.shields.io/badge/Repo-clinic--backend-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/bentlyy/clinic-backend)

Sistema full-stack para clínicas con **Node.js + Express 5 + TypeScript**, frontend en **React + Vite + MUI**, y base de datos **PostgreSQL 15**. Integra 14 módulos funcionales: agenda médica, historias clínicas electrónicas con CIE-10, recetas en PDF, facturación, órdenes de laboratorio y auditoría. Incluye **4 modelos de Machine Learning** con **TensorFlow.js**: predicción de inasistencias, clasificación de diagnósticos, forecast de demanda y detección de anomalías en signos vitales. Arquitectura con pipeline de seguridad multicapa (Helmet, HPP, Rate Limiting, JWT, RBAC, Zod), autenticación 2FA vía TOTP, multi-tenancy, i18n (4 idiomas), pruebas automatizadas con **Vitest + Supertest**, y orquestación con Docker Compose.

### 🌱 Sistema de Monitoreo Agrícola — *AgroBot Alert*
[![GitHub](https://img.shields.io/badge/Repo-AgroBot--Alert-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/bentlyy/agrobot-alert)

Plataforma de monitoreo en tiempo real para sensores IoT agrícolas conectados a **Wialon**. Backend en **Node.js + Express + MySQL 8** con motor de alertas inteligentes que evalúa condiciones (temperatura, humedad, batería) y notifica automáticamente vía **Email + WhatsApp (Twilio)**. Frontend en **React + Vite + SCSS** con mapas interactivos (Leaflet/OpenStreetMap), gráficos dinámicos (Recharts) y panel de alertas animado (Framer Motion). Incluye modo de simulación para desarrollo sin hardware real. Completamente dockerizado con Nginx como reverse proxy. Arquitectura RBAC con aislamiento de datos por usuario.

### 🤖 Plataforma de Machine Learning — *ML Portafolio*
[![GitHub](https://img.shields.io/badge/Repo-ml--portafolio-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/bentlyy/ml-portafolio)

Plataforma full-stack interactiva para entrenamiento de modelos ML con subida de datasets CSV. Backend proxy en **Express 5 + TypeScript** que se comunica con un servicio ML en **FastAPI + scikit-learn 1.6**. Soporta **12 modelos** en 4 categorías: clasificación (Random Forest, SVM, Gradient Boosting, Logistic Regression), regresión (Linear, Ridge, Random Forest Regressor, Gradient Boosting Regressor), clustering (K-Means, DBSCAN, Agglomerative) y redes neuronales (MLP). Incluye generación de datasets de ejemplo (Iris, Titanic, Housing, etc.), visualización de matriz de confusión e importancia de características, y configuración de hiperparámetros desde la UI. Frontend en **React 19 + TypeScript + Vite**. Despliegue con Docker Compose (3 servicios).

### 🔧 Sistema de Gestión de Taller Mecánico — *TallerPro*
[![GitHub](https://img.shields.io/badge/Repo-TallerMecanico-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/bentlyy/TallerMecanico)

Sistema full-stack multi-tenencia para administración integral de talleres mecánicos. Backend en **Node.js + Express 5 + TypeScript + Prisma (PostgreSQL 15)** con **Clean Architecture** (dominio, aplicación, infraestructura, presentación). Módulos completos de clientes, vehículos, órdenes de reparación con flujo de estados (EN_REVISION → EN_REPARACION → TERMINADO → ENTREGADO), gestión de inventario de repuestos con descuento automático, facturación, mecánicos y roles. Seguridad con JWT + RBAC granular (permisos JSONB), bloqueo por 5 intentos fallidos, rate limiting y Helmet. Frontend en **React 18 + Material UI 7**. Monitoreo con **Prometheus + Grafana**, documentación Swagger, y CI/CD con GitHub Actions. Totalmente dockerizado.
